Method boundary

The matrix uses a temporary localStorage-backed storage fixture. A temporary deterministic camera fixture supplies prompt, denied, granted, invalid QR, and valid QR states. The matrix tests browser route behavior only. It does not test a native permission sheet, camera hardware, or hardware QR recognition.

Native proof gaps

  • Android and iOS rendering
  • TalkBack and VoiceOver output
  • Camera permission sheets and hardware QR capture
  • Soft keyboard and native text entry
  • Dynamic Type at 200 percent
  • Safe-area insets
  • Native deep links
  • Native touch and gesture behavior
  • SQLite retention after an app restart
  • Native reduced-motion settings
