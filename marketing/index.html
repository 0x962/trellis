A FEW DETAILS

Questions &
answers

What is Trellis?+

Trellis is an app for people who work with coding agents. It connects projects, tickets, agent sessions, worktrees, diffs, and reviews.

Can I start without a ticket?+

Yes. A session can exist without a project or ticket. Its conversation and workspace remain when the agent stops.

How does Trellis use GitHub?+

Trellis represents a GitHub pull request as a diff. Link it to a ticket to track checks, review findings, an explanation, and evidence.

What is a review flow?+

A flow connects agents with defined responsibilities. A review flow can assign separate agents to correctness, security, and test coverage. Trellis records their results and findings.

Does a wave start agents automatically?+

A wave groups tickets in the plan. Wave order does not start agents or enforce dependencies. You assign the work.
